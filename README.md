# 74avto.ru — личные автомобили из Магнитогорска (GitHub Pages, статика)

## Структура (плоская, все страницы в корне)
- `index.html` — главная: 6 карточек (Camry, Scenic + 4 заглушки «Скоро в продаже»)
- `toyota-camry-1991.html` — заполненная страница (23 фото, JSON-LD Car без VIN, FAQ, блок 5%/95%, телефон владельца)
- `renault-scenic-2001.html` — заполненная страница (19 фото, JSON-LD Car с VIN, FAQ, блок 5%/95%, телефон владельца)
- `car-3.html`, `car-4.html`, `car-5.html`, `car-6.html` — пустые заготовки: фото `img/car-N/foto-1.jpg`, «Скоро в продаже», телефон владельца, кнопка «Вернуться на главную»
- `soon.html` — страница-заглушка «Скоро»
- `robots.txt` — доступ GPTBot, ClaudeBot, PerplexityBot, YandexBot + ссылка на sitemap
- `sitemap.xml` — только 3 URL (главная, Camry, Scenic); заготовки car-3..6 в sitemap НЕ включены
- `llms.txt`, `llms-full.txt` — для ИИ-поисковиков (ChatGPT, Gemini, Perplexity, Яндекс Нейро); заготовки в llms.txt НЕ включены
- `img/camry/` (23 фото), `img/scenic/` (19 фото), `img/car-3/…img/car-6/` (по одной заглушке foto-1.jpg), `img/covered.jpg`, `img/docs/`
- `style.css` — тёмный «гаражный» стиль, включая блок `.owner-phone`
- Файл `CNAME` в архив НЕ входит — добавьте сами в корень репозитория с содержимым `74avto.ru`, либо укажите домен в Settings → Pages → Custom domain

## Как заполнить пустую заготовку (car-3.html и т.д.) — без обращения к разработчику
1. Фото для каждой машины лежат в **своей папке**: `img/car-3/`, `img/car-4/` и т.д. Количество фото **не ограничено** — от 1 до 100: они все отобразятся, если добавить их в HTML. Загрузите файлы через веб-интерфейс GitHub (Add file → Upload files), именуя foto-1.jpg, foto-2.jpg и т.д.
2. Откройте `car-N.html` в любом текстовом редакторе.
3. Замените `<title>` и `<h1>` на марку/модель, `<p class="sub">` — на «Частная продажа · Магнитогорск».
4. Скопируйте строку `<img src="/img/car-3/foto-1.jpg" ...>` столько раз, сколько фото, меняя номера файлов.
5. Заполните таблицу характеристик, тексты «Состояние», «История», «Причина продажи» и FAQ (образец — camry/scenic).
6. Впишите телефон владельца в блок `.owner-phone` (номер и tel:+7XXXXXXXXXX).
7. Возьмите JSON-LD из toyota-camry-1991.html, поправьте name, url, price, mileageFromOdometer, vehicleModelDate, image (VIN — только если есть в документах).
8. Обновите meta description и og-теги.
9. На `index.html` найдите карточку `/car-3.html`, замените заголовок «—» на марку/модель, meta — на «Тип · пробег · коробка», добавьте цену.
10. Добавьте URL в `sitemap.xml` (скопируйте блок `<url>`) и при необходимости в `llms.txt`.
11. Коммит — сайт обновится автоматически.

## Публикация на GitHub Pages
1. Создайте репозиторий, загрузите содержимое архива в корень.
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. DNS у регистратора 74avto.ru: A-записи `@` → 185.199.108.153, .109, .110, .111; CNAME `www` → `<user>.github.io`.
4. В корень репозитория добавьте файл `CNAME` (одна строка: `74avto.ru`) — или укажите домен в Settings → Pages → Custom domain, включите Enforce HTTPS.

## Чего на сайте намеренно нет (GitHub Pages — чистая статика)
Формы вопросов, email-уведомления, админка, динамические статусы — всё требует сервера. Витрина: машины, фото, характеристики, телефоны. Связь — по телефонам на страницах.
