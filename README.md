# 74avto.ru — личные автомобили из Магнитогорска (GitHub Pages, статика)

## Структура (плоская, все страницы в корне)
- `index.html` — главная: 6 карточек (Camry, Scenic + 4 заглушки «Скоро в продаже»)
- `toyota-camry-1991.html` — заполненная страница (23 фото, JSON-LD Car без VIN, FAQ, блок 5%/95%)
- `renault-scenic-2001.html` — заполненная страница (19 фото, JSON-LD Car с VIN, FAQ)
- `car-3.html`, `car-4.html`, `car-5.html`, `car-6.html` — пустые заготовки: фото машины под накидкой + «Скоро в продаже»
- `contacts.html` — контакты (телефон с иконкой трубки)
- `soon.html` — страница-заглушка «Скоро»
- `robots.txt` — доступ GPTBot, ClaudeBot, PerplexityBot, YandexBot + ссылка на sitemap
- `sitemap.xml` — только 4 URL (главная, 2 машины, контакты); заготовки car-3..6 в sitemap НЕ включены
- `llms.txt`, `llms-full.txt` — для ИИ-поисковиков (ChatGPT, Gemini, Perplexity, Яндекс Нейро); заготовки в llms.txt НЕ включены
- `img/camry/`, `img/scenic/`, `img/covered.jpg`, `img/docs/` — фотографии
- `style.css` — тёмный «гаражный» стиль
- Файл `CNAME` в архив НЕ входит — добавьте сами в корень репозитория с содержимым `74avto.ru`, либо укажите домен в Settings → Pages → Custom domain

## Как заполнить пустую заготовку (car-3.html и т.д.) — без обращения к разработчику
1. Откройте файл в любом текстовом редакторе (даже Блокнот).
2. Замените `<title>Скоро в продаже — 74avto.ru</title>` на «Марка Модель Год — Магнитогорск, ЦЕНА ₽».
3. Замените текст `<h1>Скоро в продаже</h1>` на марку/модель, `<p class="sub">...</p>` — на «Частная продажа · Магнитогорск».
4. Удалите блок с `<img src="/img/covered.jpg">` и вставьте свои фото по образцу:
   <img src="/img/car-3/foto-1.jpg" alt="Марка Модель Год — фото 1" style="width:100%;border:1px solid var(--line);border-radius:6px;margin-bottom:12px">
   Фото заранее загрузите в GitHub в папку `img/car-3/` (через веб-интерфейс: Add file → Upload files).
5. Заполните таблицу характеристик (скопируйте готовые строки `<tr><td>..</td><td>..</td></tr>` и впишите свои данные).
6. Обновите тексты «Состояние», «История», «Причина продажи» и FAQ-ответы под конкретную машину (смотрите camry или scenic как образец — структура одинаковая).
7. В JSON-LD (блок `<script type="application/ld+json">` в заготовке его нет — возьмите из toyota-camry-1991.html и поправьте name, url, price, mileageFromOdometer, vehicleModelDate, image; VIN включайте только если есть в документах).
8. Обновите meta description и og-теги (og:title, og:description, og:image, og:url).
9. На главной `index.html` найдите карточку со ссылкой `/car-3.html` и замените заголовок «—» на марку/модель, meta на «Тип · пробег · коробка», добавьте цену.
10. Добавьте URL новой страницы в `sitemap.xml` (скопируйте блок `<url>` и замените loc).
11. Сделайте коммит — сайт обновится автоматически.

## Публикация на GitHub Pages
1. Создайте репозиторий, загрузите содержимое архива в корень.
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. DNS у регистратора 74avto.ru: A-записи `@` → 185.199.108.153, .109, .110, .111; CNAME `www` → `<user>.github.io`.
4. В корень репозитория добавьте файл `CNAME` (одна строка: `74avto.ru`) — или укажите домен в Settings → Pages → Custom domain, включите Enforce HTTPS.
